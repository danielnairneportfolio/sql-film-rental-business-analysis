# SQL Film Rental Business Analysis

## Project Overview

This project was developed as part of my coursework in Information Technology.
It focuses on using SQL queries to explore business operations within a film rental company, including inventory management, customer activity, financial analysis, and business relationships.

## Areas of Analysis

- Store management and location information
- Film inventory and rental pricing
- Inventory distribution across stores
- Film replacement costs
- Customer records and activity
- Customer lifetime value
- Investor and advisor information
- Film inventory coverage involving award-winning actors

## Technologies Used

- SQL

## Project Files

- `SQL-FP-Daniel_Nairne.sql` - Original SQL queries addressing eight business analysis questions.
The SQL script contains queries developed to address business reporting requirements. Some queries are incomplete or contain syntax errors.

The database schema and underlying data are not included, so the queries cannot be executed independently without a compatible database and further corrections.
